# Иврит-бот для Telegram (@hebrewVO_bot)

Интерактивный Telegram-бот для изучения **ивритского алфавита** с нуля: 31 буква, письменные и печатные формы, звуки, викторины, слова, диалоги, корни и статистика прогресса.

> **Статус:** рабочий проект, бот запущен и доступен в Telegram.

---

## ✨ Возможности

- **Алфавит**: 31 буква с озвучкой (название + звук) и картинками письменных форм
- **Письменные буквы**: отдельный блок «письменная → печатная» для изучения курсивного начертания
- **Викторины**:
  - «Звук → буква» — услышь звук и выбери букву
  - «Буква → звук» — посмотри букву и выбери звук
  - «Письменная → печатная / звук / название» — тренажёр курсива
  - «Сосчитай буквы» — найди, сколько раз встречается буква в строке
  - «Софет» — буквы в конце слова
- **Слова**: 274 слова первого уровня с озвучкой и перемешиванием букв
- **Диалоги**: 6 диалогов для выживания (проверены носителем), недельный цикл, озвучка реплик, перевод по кнопке, отметка о прочтении
- **Корни**: 25 частотных корней, поиск корней прямо в тексте диалога, каталог с пагинацией
- **Прогресс**: очки, серии (streak), уровни — всё хранится в SQLite

## 🚀 Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/VashkevichO/hebrew-bot.git
cd hebrew-bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить токен

Создайте файл `.env` из шаблона:

```bash
cp .env.example .env
```

Получите токен у [@BotFather](https://t.me/BotFather) и вставьте его в `.env`:

```
BOT_TOKEN=ваш_токен_от_botfather
```

### 4. Запустить бота

```bash
python bot.py
```

## 🎭 Диалоги

Недельный цикл: каждый понедельник бот показывает новый диалог. Отсчёт от `EPOCH = 2026-09-14`.

**Команды:**
- `/dialogue_today` — диалог этой недели
- `/dialogue` — случайный диалог

**Формат данных** — `data/dialogues.json`:

```json
{
  "id": "d01",
  "category": "знакомство",
  "title_ru": "Приветствие",
  "lines": [
    {
      "who": "a",
      "ru": "Привет! Как дела?",
      "variants": [
        { "he": "שלום! מה נשמע?" }
      ]
    }
  ]
}
```

- `who` — роль: `a` / `b`
- `variants` — варианты одной реплики (женский/мужской род, альтернативы)
- `he` — текст на иврите (без огласовок); `note` — пояснение к варианту

**Как добавлять новые диалоги:** добавить объект в массив `dialogues`. Номер недели = `неделя % len(dialogues)`, так что новые диалоги автоматически попадают в цикл.

**Озвучка:** `python generate_dialogues_audio.py` — генерирует mp3 (голос Hila, кэш по md5 в `assets/sounds/`).

## 🌱 Корни

Поиск корней работает по **подпоследовательности**, а не по подстроке: буквы корня идут в слове по порядку, между ними допускаются вставные `ו/י` (как `ה.ל.ך` → `הולך`). Служебные слова и частые заимствования отсекаются стоп-списком.

**Команды:**
- `/root <корень|слово>` — карточка корня (например, `/root שלום` или `/root ש.ל.ם`)
- Кнопка «🌱» под диалогом — корни, найденные в тексте диалога

**Формат данных** — `data/roots.json`:

```json
{
  "root": "ש.ל.ם",
  "meaning": "мир, целостность",
  "words": [
    { "he": "שלום", "ru": "мир / привет" },
    { "he": "מספר", "ru": "число", "tts": "מִסְפָּר" }
  ]
}
```

Поле `tts` — огласовки для корректного произношения, когда письмо неоднозначно.

## 🗂 Структура проекта

```
hebrew-bot/
├── bot.py                  # основной файл: команды, меню, викторины
├── dialogue_handlers.py    # хендлеры диалогов и корней (команды, кнопки)
├── utils/
│   ├── logic.py            # генерация викторин, подсказок, мотивации
│   ├── database.py         # SQLite: пользователи, прогресс, диалоги, настройки
│   ├── dialogues.py        # каталог диалогов, недельный цикл (EPOCH)
│   ├── roots.py            # каталог корней, поиск корня в слове/тексте
│   └── tts.py              # озвучка текста через edge-tts
├── data/
│   ├── alphabet.json       # 31 буква: звук, название, произношение
│   ├── words.json          # 274 слова уровня 1
│   ├── dialogues.json      # диалоги (недельный цикл)
│   └── roots.json          # корни (25 шт)
├── scripts/
│   ├── tests.py            # smoke-тесты логики бота
│   ├── test_dialogues.py   # pytest: БД диалогов + недельный цикл
│   ├── test_roots.py       # pytest: поиск корней
│   └── generate_script_images.py  # генератор картинок письменных букв
├── assets/
│   ├── fonts/              # шрифт Gveret Levin (курсив, лицензия OFL)
│   └── script/             # PNG письменных букв
├── generate_audio.py       # генератор озвучки букв
├── generate_audio_v2.py    # генератор озвучки слов
├── generate_dialogues_audio.py  # генератор озвучки диалогов
├── .env.example            # шаблон секретов
└── requirements.txt        # зависимости
```
